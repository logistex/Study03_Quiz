# 문항 점검

`questions.js`의 문항을 `CLAUDE.md`의 문항 작성 규칙 10개와 `PRD.md` 4.2로 점검한다.

**점검만 한다. 어떤 파일도 고치지 않는다.** 고칠 내용이 보이면 표의 "고칠 방향" 칸에 적기만 하고, 사용자가 따로 지시할 때까지 실제 수정은 하지 않는다.

## 대상

`$ARGUMENTS`가 비어 있으면 40문항 전부. 값이 있으면 그것을 카테고리 이름(`한국사`, `세계지리`, `과학`, `예술과 문화`) 또는 문항 id(`kh-01` 꼴)로 보고 해당하는 문항만 점검한다.

## 순서

1. `CLAUDE.md`의 규칙 10개와 `PRD.md` 4.2를 읽어 기준을 확인한다.
2. 기계로 걸러낼 수 있는 것은 아래 명령으로 먼저 뽑는다.

   ```bash
   node -e "const fs=require('fs'),vm=require('vm');const c=vm.createContext({});vm.runInContext(fs.readFileSync('questions.js','utf8')+';globalThis.Q=QUESTIONS;',c);for(const q of c.Q){const L=q.choices.map(s=>[...s].length);const bad=[];if(new Set(q.choices).size!==4)bad.push('3:보기중복');if(/않는|아닌|없는|틀린/.test(q.question))bad.push('9:부정문?');if(q.choices.some(s=>/모두|어느 것도|없음|해당 없음/.test(s)))bad.push('10:금지보기?');if(/가장|최초|최대|최소|최고|최장|최다/.test(q.question))bad.push('2:최상급-기준·시점 확인');if(Math.max(...L)>Math.min(...L)*2.5)bad.push('8:보기길이편차 '+L.join('/'));if([...q.explanation].length>60)bad.push('PRD4.2:해설 '+[...q.explanation].length+'자');if(bad.length)console.log(q.id,'|',bad.join(', '))}"
   ```

3. 기계로 판단할 수 없는 규칙은 문항을 직접 읽고 판단한다.
   - **규칙 1**: 정답이 유일한가. 다른 보기가 기준에 따라 정답이 될 여지는 없는가.
   - **규칙 2**: 최상급 표현이 있다면 기준과 시점이 문제 문장에 실제로 들어 있는가. (2단계 기계 점검은 표현만 찾아내므로 여기서 사람이 확인한다.)
   - **규칙 5**: 문제 문장이 한국어 문법에 맞고 자연스럽게 읽히는가.
   - **규칙 6**: `answer` 번호가 가리키는 보기와 `explanation`이 서로 맞는가.
   - **규칙 7**: 오답 3개가 정답과 같은 유형인가. 모르는 사람에게 답이 될 법한가. (연도만 한 자리 바꾼 식의 허수 보기는 규칙 7 위반으로 본다.)
   - **규칙 8**: 길이뿐 아니라 형식(단위, 조사, 표기)이 비슷한가.

4. **규칙 4는 파일만으로 확인할 수 없다.** `questions.js`에는 문항마다 출처가 하나만 기록되어 있어 "출처 2곳 이상"을 검증할 근거가 없다. 규칙 4는 판정하지 말고, 보고서 끝에 확인하지 못했다고 밝힌다. 사용자가 원하면 그때 WebFetch로 출처를 열어 대조한다.

## 보고 형식

어긋난 문항만 표로 낸다. 통과한 문항은 표에 넣지 않는다.

| id | 카테고리 | 어긴 규칙 | 문제가 되는 부분 | 고칠 방향 |
|---|---|---|---|---|
| kh-03 | 한국사 | 2, 8 | (해당 문장이나 보기를 그대로 인용) | (한 줄 제안) |

- "어긴 규칙" 칸에는 CLAUDE.md의 규칙 **번호**를 적는다. PRD 4.2 위반은 `PRD4.2`로 적는다.
- 한 문항이 여러 규칙을 어기면 번호를 쉼표로 나열한다.
- 확실하지 않고 사람이 판단해야 하는 것은 번호 뒤에 `?`를 붙이고, 왜 애매한지 "문제가 되는 부분"에 적는다.

표 뒤에 다음을 덧붙인다.

- 점검한 문항 수와 어긋난 문항 수
- 규칙 4는 확인하지 못했다는 안내
- 파일을 고치지 않았다는 확인
